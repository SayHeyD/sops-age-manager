## sam key copy

Copy key attributes (public key, private key, or name) to clipboard

### Synopsis

Copies the recipient public key (age1...), private key, or key name 
of the specified key to the system clipboard. By default, the public key is copied.

```
sam key copy [flags]
```

### Options

  -h, --help      help for copy
  -n, --name      copies the key name

  -p, --public    copies the public key (recipient)
